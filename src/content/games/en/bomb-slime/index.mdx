## **Core Gameplay**

In **Bomb Slime**, you play a slime that reels bombs in with a **rope gun** to swallow them, then spits them back out as armed projectiles to trigger **chain explosions**. Levels combine breakable walls, zero-gravity floating bombs, timed hazards, and state-restoring checkpoints. Players chain rope swings, wall-smashing dashes, wall slides, and ceiling crawls to traverse rooms at high speed. When you die, the level itself rewinds alongside the player so shattered walls and spent bombs are restored for a clean retry.

## **My Role**

Working in a **5-person team** as **Lead Designer, Lead Programmer, and Level Designer**, I owned the core mechanics, runtime system architecture, and playtest telemetry toolchain:

- **Decoupled Event-Bus Architecture**: Architected eight domain-specific static event buses to decouple gameplay simulation from presentation directors. Gameplay systems emit pure domain events while dedicated presentation controllers handle screen shake, hit-stop, camera zoom punches, priority-pooled 3D spatial audio across desktop and WebGL, gamepad rumble and adaptive trigger haptics, and death/respawn sequences.
- **Composable Interactable Framework and State Rewind**: Built a modular interactable object framework assembled from orthogonal components for detonation, breakable terrain, rope-reel carrying and swallowing, zero-gravity knockback, and state restoration. Paired this with a memento-based checkpoint snapshot system that rewinds the entire room state upon respawn, and an automated geometry recovery solver that frees players wedged into terrain during high-speed dashes or blasts.
- **Playtest Telemetry and Visual Level Analytics Suite**: Engineered an in-game telemetry recorder that logs Git-stamped CSV data covering player trajectories, death coordinates and causes, mechanic usage, frame times, and per-checkpoint segment metrics. Built a standalone offline web analytics dashboard and a matching Unity Editor scene view overlay that render death heatmaps, lethality contours, ghost replays, and difficulty curves directly over exported level art.
