## **About**

**Wolves of Wand Street** is a card-driven area-control tabletop game for 3–4 players. A full match takes about 10 minutes across 3 simultaneous-action rounds.

## **My Role**

I was responsible for **rules design** and **automated playtesting**:

- **Rules and Economy Design**: Working from the core turn structure, I designed 26 distinct action card rules and the player resource management economy, evolving the prototype from sequential turns into a fast-paced simultaneous-action format.
- **Automated Playtesting with MCTS**: Built an automated simulation testing suite based on the game rules and the Monte Carlo Tree Search algorithm to verify rule consistency across thousands of simulated matches, rebalancing card costs and territorial scoring weights from the resulting metrics.

## **How to Play**

- **Online**: Import the playable room package from the GitHub repository into playingcards.io.
- **In Person**: Download and print the print-and-play PDF sheet available in the GitHub repository.
