## **Overview**

**Unknown Technology** is a first-person museum puzzle game vertical slice built in Unity 6 by a **6-person team**. Players step into the role of a night curator investigating missing technology relics across Ancient, Modern, and Future exhibition halls and restoring them with a sceptre. As **Lead Programmer**, I created the foundational game architecture, built the core UI framework, implemented the sceptre mechanics, established the automated testing workflow and engineering standards, and reviewed all code submitted by team members.

## **Core Responsibilities & Technical Highlights**

- **Foundational Game Architecture and Cross-Scene Persistence**: Created a guarded five-phase state machine and centralised event system governing boot, main menu, asynchronous scene loading, exploration, and pause flows. Isolated input action maps by game phase to prevent gameplay input bleed while paused, with seamless keyboard, mouse, and gamepad switching and automatic pause notices on controller disconnect. Engineered an atomic three-slot save system that captures and silently restores the exact pose and slot state of every relic and gate across exhibition eras.
- **Foundational UI Framework and Accessibility**: Built the main menu, save-slot management flow, era HUD, pause overlay, and live settings menu using Unity UI Toolkit with focus-based gamepad navigation. Implemented persistent accessibility and control options including UI scaling, independent mouse and gamepad sensitivity, Y-axis inversion, and a reduced motion mode that suppresses camera and sceptre head-bob.
- **Sceptre Telekinesis and Anti-Clipping Physics**: Implemented the first-person sceptre aiming, beam rendering, and telekinetic relic carrying system. Replaced raw transform teleportation with velocity-driven continuous dynamic rigidbodies, line-of-sight obstruction breaking, and swept slot-snapping validation so carried relics never clip through walls or snap across solid geometry.
- **Automated Testing Workflow, Coding Standards and Code Review**: Established a clean project structure and coding standards, built an automated unit test suite covering phase transitions, settings persistence, and save serialisation using the Unity Test Framework, and created one-click editor scene generation tooling. Reviewed all teammate pull requests across puzzle mechanics, NPC quizzes, audio, and environment interactions to ensure architectural consistency and clean merges.
