## **关于项目**

**PTG** 是一套基于 Unity 6 构建的交互式、随机种子驱动的 3D 程序化地形生成工具套件，面向技术美术、关卡策划与工具程序员。底层算法完全采用零引擎 API 依赖的纯 C# 编写，支持通过实时调节多维噪声与色彩参数，在 60 帧单帧时间预算内即时生成严格可复现的平面、环礁岛屿及六面体立方球行星地形。

## **核心功能与工程亮点**

- **纯 C# 确定性噪声与多重分形核心**：独立从底层实现高质量伪随机数生成器、多维梯度噪声与多重分形反馈算法，完全脱离第三方开源库依赖。自主排查并修复了晶格点积计算中纵轴梯度缺失导致的地形方向性拉伸问题，并在六面体投影立方球行星拼接处实现共享边界顶点法线平均焊接，彻底消除星球表面光照接缝。
- **多核并行加速与 60 帧实时交互性能**：内置低开销分段性能遥测工具与独立网页对比看板。通过移除冗余碰撞体烘焙、引入高度矩阵缓存快速重着色通道以及多核并行计算优化，在 257×257 标准分辨率下将单次完整地形生成耗时从 **144.8 毫秒压缩至 10.5 毫秒**，实现 **13.79 倍加速**；在 513×513 超高分辨率下实现 **15.02 倍加速**，且单独调整材质配色耗时仅需 **0.8 至 1.9 毫秒**。
- **UI Toolkit 双栏工作流与多维地形表现**：采用双栏界面布局，提供包含高度、坡度与混合权重的八层地表着色面板、自研内置 HSV 拾色器、单色偏移着色器驱动的三态线框叠加视图、全参数通俗化悬停提示、双模式自由飞行相机以及一键界面隐藏功能；动态将高分辨率网格索引缓冲区升级为 32 位，突破单网格六万五千顶点上限。
- **49 项自动化单元测试与两轮用户可用性验证**：编写 49 项编辑器自动化单元测试，验证随机种子分布、分形能量梯度、线框拓扑完整性，以及多线程并行计算与单线程串行计算在每个网格顶点上的逐位完全一致性。组织两轮真实用户测试与三项逆向地形还原任务，界面清晰度获 **8.00 / 10** 分、参数易懂度获 **7.14 / 10** 分，所有核心可用性反馈均在敏捷迭代闭环中完成工程落地。
