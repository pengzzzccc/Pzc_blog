## 核心玩法

在《Bomb Slime》中，你扮演一只能利用**绳索枪（Rope Gun）**将炸弹拉回吞下、再吐出去引发**连锁爆炸（Chain Detonation）**的史莱姆。关卡由可破坏墙体、零重力浮空炸弹、定时机关与检查点构成。玩家可以结合绳索摆荡、破墙冲刺（Dash）、蹬墙跳与天花板吸附实现高速机动；死亡时不仅玩家重生，整个关卡的破坏状态与已消耗炸弹也会通过快照机制完整回溯。

## 我的职责（5 人团队）

我担任项目的**主策划、主程序与关卡设计**，主导核心机制设计、底层系统架构与全链路测试分析工具链搭建：

- **事件驱动架构（8 条静态事件总线 + Director 模式）**：设计并实现 `PlayerBus`、`LifeBus`、`ItemBus`、`HazardBus`、`FxBus`、`RopeGunBus`、`LevelBus` 与 `UiBus`，将底层玩法逻辑与表现层（镜头震动/帧冻结 `FxDirector`、3D 空间音效池 `AudioDirector`、手柄震动与 DualSense 自适应扳机 `HapticsDirector`、死亡与检查点重生 `DeathDirector` / `RespawnDirector`）彻底解耦。
- **可组合交互物框架（Composable Interactable Parts）**：将炸弹、可破坏物与机关抽象为由正交组件拼装的 `Interactable` 节点（`ExplodePart`、`BreakablePart`、`CarriablePart`、`FloatablePart`、`RestorablePart`、`HarmOnTouch` 等），并在 `GameManager` 上实现基于备忘录模式的 `LevelMemento`，在死亡重生时零开销回滚全场景状态，同时编写 `UnstuckSolver` 解决高速运动卡墙边界问题。
- **Playtest 遥测与可视化关卡分析工具（PerfLog Viewer & Scene Overlay）**：开发游戏内 `PerformanceRecorder`（记录带 Git 分支/提交戳的周期采样、死亡坐标、致死源、绳索/移动状态及检查点分段耗时 CSV），配套构建离线 Web 分析器 **PerfLog Viewer**（支持实景关卡底图叠加死亡热力、致死率、停留热力、玩家动线幽灵回放、检查点分段难度曲线及 FPS/GC 联动分析）以及 Unity 编辑器内的 `PerfLog Scene Overlay` 与自动化世界校验工具。
