## **关于项目**

**Wolves of Wand Street** 是一款面向 3–4 名玩家的卡牌驱动区域控制桌游，单局时长约 10 分钟，共包含 3 轮同时行动博弈。

## **我的职责**

我负责项目的**规则设计**与**自动化游戏测试**：

- **规则与经济系统设计**：基于核心回合框架，设计 26 种功能各异的行动卡牌规则以及金币与投资者的资源管理体系，将游戏从早期的顺序回合原型迭代为快节奏的同时行动模式。
- **MCTS 自动化平衡测试**：基于游戏规则与蒙特卡洛树搜索算法搭建自动化对局模拟测试程序，运行数千局模拟对战以检验规则一致性与数值平衡，并根据量化统计结果调整卡牌费用与领地计分权重。

## **游玩方式**

- **线上游玩**：在 playingcards.io 平台导入 GitHub 仓库中提供的线上桌游房间包文件即可直接开局。
- **线下桌游**：下载并打印 GitHub 仓库中的打印版卡牌与版图 PDF 文件即可进行实体游玩。
