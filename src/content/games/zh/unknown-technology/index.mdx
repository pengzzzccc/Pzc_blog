## **关于项目**

**Unknown Technology** 是一款由 **6 人团队**基于 Unity 6 开发的第一人称博物馆解谜游戏垂直切片。玩家扮演一名夜间策展人，在古代、现代与未来三个时代的展厅中调查失踪的科技遗物，并使用权杖将其复原。我在团队中担任**主程序员**，负责创建游戏基础架构、搭建基础 UI、实现权杖核心功能、建立自动化测试流程与规范，并负责审查全部队员提交的代码。

## **核心职责与技术亮点**

- **游戏基础架构与跨场景状态持久化**：创建全局五阶段受保护状态机与事件通信中心，统一管控启动、主菜单、异步加载、探索与暂停状态流转。按游戏阶段对输入系统进行结构化隔离，从架构层面杜绝暂停时的输入穿透，并支持键鼠与手柄无缝切换及手柄断连自动暂停提示。设计三槽位原子写入存档系统，完整记录并静默还原各时代展厅内所有可抓取遗物的位姿、插槽状态与机关门状态。
- **基础 UI 框架与无障碍体验**：基于 Unity UI Toolkit 搭建主菜单、三存档槽位管理、时代 HUD、暂停菜单与实时设置面板。支持 UI 整体缩放、鼠标与手柄独立灵敏度、Y 轴反转以及减弱动态效果模式，开启后自动抑制第一人称镜头与权杖的行走晃动。
- **权杖核心功能与物理防穿墙交互**：实现第一人称权杖瞄准、能量光束渲染以及隔空抓取遗物功能。采用无重力连续碰撞动态刚体速度牵引替代直接修改坐标，配合相机视线阻挡断连判定与插槽步进扫掠检测，彻底解决手持遗物穿墙及隔墙非法吸附问题，并提供插槽放置校验接口供谜题模块调用。
- **自动化测试流程、工程规范与代码审查**：制定扁平化单程序集目录与编码规范，搭建覆盖状态机流转、设置持久化与存档读写的编辑器自动化单元测试套件，并提供一键场景与预制体构建工具。通过 GitHub Pull Request 审查队员提交的壁画拼图、历史问答、音频与场景交互代码，解决合并冲突并保障主干架构稳定。
